# Homebrew tap for Mickey

[Mickey](https://github.com/Arrows78/Mickey) is a menu-bar cursor highlighter and presentation toolkit for macOS.

## Install

```bash
brew install arrows78/mickey/mickey
```

Use the full name above. Homebrew 7 only loads casks from third-party taps you trust, and naming the tap in the command trusts that cask. If you ran `brew tap arrows78/mickey` first, trust the tap before installing:

```bash
brew trust --tap arrows78/mickey
brew install --cask mickey
```

Update with `brew upgrade --cask mickey`.

## First launch

Mickey is signed ad hoc and not notarized, so macOS blocks the first launch. Open **System Settings › Privacy & Security** and click **Open Anyway**, or run:

```bash
xattr -dr com.apple.quarantine /Applications/Mickey.app
```

## Uninstall

```bash
brew uninstall --cask mickey         # keeps your settings
brew uninstall --zap --cask mickey   # also removes Mickey's settings
```

Your recordings in `~/Movies/Mickey` are never removed.

## About this repository

`Casks/mickey.rb` is generated by the release workflow of the [Mickey repository](https://github.com/Arrows78/Mickey) on every release. Do not edit it by hand.
